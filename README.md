
# 🎬 CineGen AI

**AI Prompt to Video Studio**

CineGen AI is a creative video studio that transforms text prompts into animated video previews.

## ✨ Features

- AI-style prompt interface
- Multiple visual styles
- Landscape, portrait and square ratios
- Animated video preview
- Storyboard generation
- Play and pause controls
- WebM video download
- Responsive mobile interface

## 🚀 Technologies

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Android WebView
- GitHub Actions

## 📱 Android App

CineGen AI can be packaged as an Android APK using GitHub Actions.

## ⚠️ Important

The current version generates demo animations using HTML Canvas.

Real AI video generation requires integration with an AI video generation API and a secure backend.
